# 拼车模式

部署时设置环境变量 `RUN_MODE=carpool`，重启后生效。默认仍为 `standard`。

拼车模式关闭以下功能的页面入口与 API，即使数据库中原有开关已启用也不会开放：

- 推广返佣、邀请奖励、返佣转账及返佣管理。
- 优惠码及其注册奖励。
- 在线支付、购买和续费、订单与支付管理、支付回调。
- 兑换码领取、创建和管理。
- 模型广场、批量生图工作台及批量生图接口。普通图片生成接口不受此限制。
- 自定义页面与用户、管理员自定义菜单。
- 开放注册及注册赠送余额、订阅和平台额度；第三方登录也不能自动创建新用户。已有用户登录和管理员创建用户不受影响。

保留用户、分组、上游账号、API 密钥、订阅分配与到期时间管理、用量统计和日／周／月配额限制，包括分组批量重置已用额度。管理员可继续手动维护订阅。

注册邀请码仍作为注册访问控制保留，与推广奖励不同；现有邀请码仍可验证。拼车模式不提供兑换码管理入口。

此模式不删除历史订单、返佣、兑换码或其他业务数据。切换回 `standard` 后按原有设置恢复入口。切换前应先处理未完成的在线支付订单，因为拼车模式拒绝支付回调。

它与 `simple` 模式不同：拼车模式不会跳过计费和配额检查。本次代码修改不自动切换线上运行模式，也不触发构建或部署。
